# Portfolio Personal

Portfolio personal desarrollado con **React**, **TypeScript** y **CSS**, donde presento información sobre mí, mi formación, proyectos y medios de contacto.

## 🚀 Tecnologías

- React
- TypeScript
- CSS
- Vite

## ✨ Características

- Diseño responsive.
- Navegación entre secciones.
- Sección de presentación.
- Información personal y habilidades.
- Proyectos destacados.
- Formación académica.
- Formulario de contacto.

## 📁 Estructura del proyecto

```text
src/
├── assets/
├── components/
│   ├── About/
│   ├── Contact/
│   ├── Education/
│   ├── Footer/
│   ├── Header/
│   ├── Home/
│   ├── Nav/
│   └── Projects/
├── helpers/
├── App.css
├── App.tsx
├── index.css
└── main.tsx
```

## 📦 Instalación

1. Clona el repositorio:

```bash
git clone https://github.com/tu-usuario/portfolio.git
```

2. Accede al proyecto:

```bash
cd portfolio
```

3. Instala las dependencias:

```bash
npm install
```

4. Inicia el servidor de desarrollo:

```bash
npm run dev
```
